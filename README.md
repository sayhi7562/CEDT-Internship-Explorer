# CEDT Internship Explorer

Built by sayhi7562 and GPT-5.

## Overview
The internship site is hard to scan and sort, so this project presents the same data with a cleaner, faster UI. It supports filters, sorting, and a more readable job layout.

## Features
- Search by position or company
- Filter by tags and working conditions
- Sort by compensation, popularity, or title
- Optional bookmark-only view
- Fetch data directly from the official site using a cookie

## Tech Stack
- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Notes
- To load real internship data, you need a valid cookie from the official internship site.
- The cookie is used only for the request and is not stored.

## Scripts
- `npm run dev` - start dev server
- `npm run build` - production build
- `npm run start` - run production server
